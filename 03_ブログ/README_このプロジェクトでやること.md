# ブログ プロジェクト

## このプロジェクトで扱うこと

- X-rayブログ
- 整形領域X線撮影ブログ
- 若手診療放射線技師向け記事
- 撮影法解説
- SEOタイトル
- メタディスクリプション
- サムネ案
- 関連記事設計
- リライト管理

## チャット開始時の言い方

```text
今日はブログだけ作業します。
```

## 主なフォルダ

- `X-rayブログ`
- `X-rayブログ_整形撮影ブログ制作工場`

## 作業ルール

- 撮影法ごとに新規Markdownファイルを作る
- 既存記事に別テーマを上書きしない
- 記事ごとにSEO、撮影イメージ、チェックポイントを入れる
- はてなブログへ貼る本文は、原則HTML形式で作る
- 記事冒頭には撮影体位が分かる画像を置き、その下に本文を続ける
- 見出しは左線付きの`h2`、重要語は`strong`または赤字強調、条件は`table`で整理する
- Markdownの`##`やHTMLタグがそのまま見えないよう、貼り付け先の編集モードを確認する
