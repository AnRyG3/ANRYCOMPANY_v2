# 患者服装 参考画像 採用メモ

このフォルダは、患者キャラクターの季節別ファッション参考を保管する場所。

## 採用ルール

- 画像生成時は、該当する年代・季節の `_ref.png` を参照する。
- 検査着は既存作成済みのものを使用し、このフォルダでは新規作成しない。
- 20代・30代・40代患者に、白ブラウスとベージュパンツの組み合わせは使用しない。
- 参考服装は服装・季節感の参照用。顔は各Character IDの既存顔を優先する。
