# 放射線技師の安心ラボ Instagramリール制作工場

## 目的

医療知識を一般の方向けにわかりやすく伝え、不安を安心に変えるリールを継続的に作る。

## 全体フロー

1. `01_ネタ` でテーマを選ぶ
2. `02_台本` で台本を作る
3. 台本を120点基準で見直す
4. 画像素材を作る
5. ナレーションを作る
6. VrewまたはCapCutで字幕・編集を行う
7. `07_投稿済` に完成物と投稿情報を保存する
8. 投稿後は分析へ回す

## 投稿情報の保存ルール

投稿タイトル・説明文・ハッシュタグは、チャット欄だけに残さない。

完成したら必ず次の2か所に保存する。

- 制作工場: `F:\ANRYCAMPANY\01_ショート動画_リール_YouTubeShorts\放射線技師の安心ラボ_制作工場\07_投稿済\投稿情報`
- Obsidian: `F:\ANRYCAMPANY\ANRYCAMPANY\投稿情報`

投稿情報ファイルには、必ず次を入れる。

- 動画タイトル
- 投稿タイトル
- 説明文
- ハッシュタグ
- 素材場所

## 制作ルール

- 最初の3秒で興味を引く
- 難しい言葉を使いすぎない
- 一般の方の誤解をほどく
- 医療不安を煽りすぎない
- 最後は安心感で終える
- 保存CTAを入れる
- 次回予告を入れる
- 画像は縦9:16で作る
- 同じ動画内で登場する人物は、容姿・髪型・服装・服の色を統一する
- シリーズ動画では、ユーザー指定の参照モデルを使い、患者さんの人物設定をシリーズ全体で統一する
- 参照モデルの指定がない場合は、画像生成前にユーザーへ確認する
- 別シリーズや続編では、前回の人物設定を自動で引き継がない
- 完成後は投稿情報を必ず保存する
