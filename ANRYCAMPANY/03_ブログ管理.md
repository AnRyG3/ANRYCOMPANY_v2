- # 足関節外側靭帯損傷における特殊撮影技術と臨床評価：ATFL view（原口法）およびストレス撮影の専門レポート

## 1. はじめに：足関節捻挫における画像診断の重要性

足関節捻挫はスポーツ外傷の中で最も頻度が高く、アスリートの競技離脱の主要な原因です。その約85%は外側靭帯複合体の損傷であり、特に前距腓靭帯（ATFL）の損傷が中心となります。

臨床現場において、Ottawa Ankle Rules（オタワ足関節ルール）に基づく標準的なX線撮影（正面、側像、モルティス像）は、重大な骨折を否定する上で96～99%という極めて高い感度を有しています。しかし、軟部組織である靭帯そのものや、ATFLの付着部剥離骨折（裂離骨折）を検出するには、標準的な投影法だけでは不十分です。特に剥離骨折は、骨片が腓骨遠位端と重なることで見逃されやすく、適切な治療戦略を立てるためにはATFLを接線方向に捉える特殊撮影技術が不可欠となります。

## 2. 前距腓靭帯（ATFL）の解剖学的・病態生理学的特性

ATFLは外側靭帯複合体の中で最も脆弱であり、解剖学的に以下の特徴を持ちます。

### 解剖学的特性

- **起始**: 腓骨遠位端（外果）の前縁
- **停止**: 距骨頭の頸部（外側関節面の直前）
- **走行**: 前方、下方、内方へと斜めに走行する扁平なバンド状
- **サイズ**: 厚さ1.5～2.5 mm、長さ10～12 mm（Source 2に基づく）
- **機能**: 足関節底屈位における距骨の前方移動および内反の制動

### 損傷機序

足関節が**底屈位かつ内がえし（内反）**を強制された際、ATFLは最大緊張に達し、その強度を超えた場合に損傷します。これは外側靭帯の中で最も弱いため、捻挫において初発かつ最頻の損傷部位となります。

### 低位足関節捻挫の分類（Grade I〜III）

臨床的特徴に基づき、以下のグレードに分類されます。

|   |   |   |   |
|---|---|---|---|
|損傷グレード|靭帯の状態|腫脹・皮下出血|荷重時の痛み|
|**Grade I**|断裂なし（伸展のみ）|最小限|正常（可能）|
|**Grade II**|部分断裂|中等度|軽度〜中等度|
|**Grade III**|完全断裂|重度|重度（困難）|

## 3. ATFL view（原口法）の撮影技術と評価基準

通常のX線撮影では、ATFL付着部剥離骨折の80%以上が診断困難とされています。これを打破するのが「原口法」です。

### 撮影手技の詳細（診療放射線技師向け技術指針）

正確な「ATFL view」を得るためには、骨片を腓骨から分離し、接線方向に描出する必要があります。

- **肢位**: 患者を仰臥位とし、足関節を**底屈45度**に保持。
- **角度調整**: 足部を**内側から15度挙上**（足外側を下にする）させ、足底を浮かせる。
- **撮影のポイント**: 疼痛により規定の底屈角が得られない場合は、無理に動かさず、中心線を尾側に振るなどの補正を検討します。また、包括的な評価として、原口法には**CFL view（内旋45度位）**も存在することを念頭に置き、医師の指示に応じて追加を検討すべきです。

### 画像の評価基準

- **「良い写真」の条件**: 外果前縁が鮮明な輪郭として描出され、距骨との重なりが最小限であること。
- **臨床的価値**: 本法を用いることで、見逃されやすい微細な骨片を確実に描出できます。特に小児（10〜12歳）の外果剥離骨折において、MRIに頼らずともX線のみで確定診断を下すことが可能になります。なお、9歳以下の小児では、剥離部位がまだ骨化していない軟骨である可能性があり、X線に写らない場合があるため、超音波検査（US）の併用が重要です。

## 4. 足関節ストレス撮影の技術と定量的評価

靭帯の機能的不安定性を定量化するために、以下のストレス撮影を実施します。

### 前方引き出し撮影（Anterior Drawer Test）

- **目的**: ATFLの制動機能を評価。
- **手技のコツ**: **ATFLの評価には底屈位**で行い、**CFL（踵腓靭帯）の評価を兼ねる場合は背屈位**で行うのが最適です。
- **基準**: 側像にて、脛骨に対する距骨の前方移動距離を計測します。

### 内反ストレス撮影（Talar Tilt Test）

- **評価基準**: 距骨傾斜角を計測し、**健側差が15度以上**ある場合に靭帯複合体（ATFL+CFL）の陽性所見と判断します。

### 外旋ストレス撮影（シンスデスモーシス評価）

高位足関節捻挫が疑われる場合、モルティス像での評価が重要です。

- **内側関節腔（Medial Clear Space）**: 4mm以上の拡大で陽性。
- **脛腓間透明帯（Tibiofibular Clear Space）**: 6mm以上の拡大で陽性。

## 5. 整形外科医が重視する読影と臨床鑑別のポイント

### 剥離骨折と副腓骨（Os subfibulare）の鑑別

画像上での誤診を防ぐため、以下の形態的特徴を注視します。

- **副腓骨**: 既存の過剰骨。骨片の縁が**平滑（スムーズ）で、硬化像**（白い縁取り）を伴う。
- **急性剥離骨折**: 縁が**不整（シャープ・ギザギザ）**であり、臨床的な圧痛部位と一致する。

### 治療方針への影響

- **小児の剥離骨折**: 底屈動作により靭帯が骨片を遠位に牽引し、癒合を阻害します。そのため、靭帯修復目的のU字キャストではなく、底屈を制限する**L字キャストでの強固な固定**が選択される場合があります。
- **手術の検討**: Brostrom法（解剖学的修復術）などの適応は、これらストレス撮影による不安定性の定量評価に基づいて決定されます。

## 6. 超音波診断（US）とMRIの役割：補完的検査の活用

### 超音波検査（US）の利点

ベッドサイドで迅速に行える動的評価として、ATFL損傷に対し**感度94.4%、特異度100%**という極めて高い精度を誇ります。リアルタイムでストレスを加えながら靭帯の連続性を確認できるため、特に骨化前の小児や急性期の迅速診断に有用です。

### MRIの適応

軟部組織全体の精査に用いられ、特に以下の評価に優れます。

- **関節内病変**: 最も頻度の高い病態である**前・前外側滑膜炎（Anterior/Anterolateral Synovitis）**の検出。
- **骨・腱損傷**: 骨軟骨損傷（OCD）、腓骨筋腱損傷、シンスデスモーシス損傷の同定。
- **持続痛の精査**: 受傷後6〜8週間経過しても疼痛が残存する場合の二次検査。

## 7. 結論：診療放射線技師へのメッセージ

足関節捻挫の画像診断において、技師に求められるのは単なる撮影作業ではなく、臨床解剖に基づいた「診断に寄与する画像」の提供です。原口法における底屈45度・内側15度という正確なポジショニングが、80%もの剥離骨折の見逃しを防ぐ鍵となります。

「たかが捻挫」と軽視せず、小児における骨化の進展度や、ストレス撮影時の足首の角度といった細部へのこだわりが、正確な診断と患者の早期復帰、そして慢性不安定性への移行防止に直結することを再認識してください。医師との密な情報共有を通じて、最適な撮影法を自ら提案できるプロフェッショナルを目指しましょう。

- # 足関節外側靭帯損傷におけるCFL viewの撮影技術と臨床的読影指標

### 1. はじめに：CFL viewの必要性と本レポートの目的

足関節捻挫、特に低位捻挫（low ankle sprain）の診断において、標準的な3方向撮影（正面、側面、斜位/モルチス像）は骨折の除外には有効ですが、靭帯付着部の微細な剥離骨折を評価するには不十分です。標準的な正面像（AP像）では、外果（腓骨遠位端）と距骨・脛骨が重なり合うため、靭帯付着部の詳細な観察が物理的に困難だからです。

本レポートでは、踵腓靭帯（CFL）の損傷および付着部剥離骨折の検出に特化した特殊撮影法「CFL view」を理論的に解説します。我々診療放射線技師が、標準撮影では死角となる「外果後下縁」を明瞭に描出することは、診断精度の向上と適切な初期治療の選択に直結する極めて重要な任務です。

### 2. 解剖学的および病態学的基礎

足関節外側靭帯複合体は、以下の3つの主要な靭帯で構成されています。損傷頻度の高い順に整理します。

1. **前距腓靭帯（ATFL）：** 外側靭帯の中で最も損傷頻度が高い。
2. **踵腓靭帯（CFL）：** 2番目に損傷頻度が高い。足関節だけでなく距骨下関節の安定性にも関与する。
3. **後距腓靭帯（PTFL）：** 損傷頻度は比較的低い。

ATFLとCFLでは、損傷に至るメカニズムと推奨される理学テストが異なります。

|   |   |   |
|---|---|---|
|項目|前距腓靭帯（ATFL）|踵腓靭帯（CFL）|
|**損傷頻度の順位**|第1位|第2位|
|**受傷時の肢位**|底屈 ＋ 内反|**背屈** ＋ 内反|
|**理学所見の適応**|前方引き出しテスト（底屈位）|前方引き出しテスト（背屈位）/ 距骨傾斜テスト|

### 3. 撮影技術：CFL viewのポジショニング・ポイント

CFL viewの目的は、CFLの付着部である「外果後下縁」のプロファイルを他組織との重なりなく描出することにあります。

**撮影手順**

1. 患者を撮影台の上に臥位、または座位（下肢伸展位）にします。
2. **足関節の肢位：** 足関節を底背屈させない「中間位（Neutral position）」に保持します。
3. **回旋角度：** 下肢全体を股関節から**45度内旋（Internal Rotation）**させます。
4. 中心線は外果に向けて垂直に入射します。

**シニア技師の技術的解説とコツ**

- **45度内旋の幾何学的根拠：** 腓骨遠位の後縁は、解剖学的に斜め後方に位置しています。下肢を45度内旋させることで、この**外果後縁をX線に対して接線（tangential）方向に投影**することが可能となり、距骨や脛骨遠位端との重なりを最小限に抑えた明瞭なプロファイルが得られます。
- **補助具の活用と疼痛管理：** 捻挫直後の患者は内反・底屈動作に強い痛みを感じます。足先だけで角度を作ろうとすると不安定になり、また患者も無意識に抵抗（防御性収縮）してしまいます。角度のついたスポンジ等の補助具を下肢全体の下に敷き、膝関節から足首までを「面」で支えるように保持してください。これにより、患者の苦痛を和らげながら、正確な45度内旋を維持した安定した画像を提供できます。

### 4. 画像の評価基準：良い写真と悪い写真の条件

撮影後、直ちに以下のチェックリストを用いて画像の診断価値を評価してください。

- [ ] **外果の後下縁（distal posterior margin）**の輪郭が、他組織と重ならず鮮明に独立して描出されているか
- [ ] 足関節が底屈・背屈に偏らず、中間位で投影されているか
- [ ] 剥離骨片や軟部組織の腫脹を判別できる適切なコントラストが確保されているか

**画質の対比**

- **良い写真（診断価値が高い画像）：** 外果後下縁の骨輪郭がシャープであり、靭帯付着部の微細な変化が手に取るようにわかる。
- **悪い写真（再撮影が必要な画像）：** 内旋角度の不足、あるいは過度な内旋により、**外果後縁の陰影が脛骨遠位端の濃い不透過像の中に埋もれてしまっている状態**。これでは剥離骨片の有無を判定できず、特殊撮影の意味をなしません。

### 5. 臨床的読影指標と剥離骨折の検出

CFL viewにおいて、整形外科医は**「外果後下縁（腓骨遠位後縁）」**のわずかな骨片の有無を注視します。

- **剥離骨折（avulsion fracture）の検出：** 標準的なAP像で見逃されやすい微細な骨片も、接線投影であるCFL viewなら検出可能です。
- **小児（10〜12歳）における特異性と緊張感：** この年代は未骨化の軟骨部分が含まれるため、剥離骨折が発生しやすい極めて重要な時期です。**X線に写る微細な骨片は「氷山の一角」であり、その周囲には未骨化の軟骨損傷が隠れている可能性がある**という緊張感を持って撮影に臨む必要があります。
- **治療方針への決定的な影響：** 剥離骨折が確認された場合、通常の靭帯損傷よりも厳重な固定が検討されます。損傷メカニズム上、**底屈動作によって骨片が遠位に牽引される**ため、これを防ぐL字キャスト固定などが選択されます。我々の提供する1枚の画像が、固定の要否を左右するのです。

### 6. ATFL viewとの相補的な役割

東京警察病院の原口直樹先生が提唱した「ATFL view」と、この「CFL view」をセットで運用することで、外果の全周的な評価が可能になります。

|   |   |   |
|---|---|---|
|項目|ATFL view|CFL view|
|**肢位（ポジショニング）**|底屈45度、内側を15度挙上（**回外/supination**に近い動き）|中間位、45度内旋|
|**ターゲット部位**|**外果前縁**|**外果後下縁**|
|**臨床的目的**|前距腓靭帯の剥離骨折検出|踵腓靭帯の剥離骨折検出|

ATFL viewは「前方」、CFL viewは「後下法」というように、ターゲットとする解剖学的部位が明確に異なります。これら2つの特殊ビューを組み合わせることで、標準撮影の死角を完全に網羅し、剥離骨折の見逃しを最小限に抑える「相補的システム」が完成します。

### 7. まとめ

診療放射線技師が理論に基づいた正確なCFL viewを提供することは、整形外科診断において以下の価値を持ちます。

- **診断精度の飛躍的向上：** 標準撮影では不可能な「外果後下縁」の接線投影により、微細な剥離骨折を確実に描出できる。
- **小児医療への貢献：** MRI等の高額・長時間検査に頼らずとも、X線写真だけで迅速かつ確実な確定診断を可能にする。
- **モダリティの相補的活用：** 近年普及しているエコー（超音波検査）は「骨膜の連続性の断絶」や靭帯・軟部組織の「動的な評価」に優れますが、X線撮影は「骨片の全体的な位置関係」を静止画として俯瞰できる強みがあります。

我々技師は、単にシャッターを押すのではなく、解剖学的・幾何学的根拠を持って最適な「1枚」を提供しなければなりません。それがスポーツ整形外科領域におけるプロフェッショナルとしての誇りです。
