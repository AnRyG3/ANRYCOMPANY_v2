# Codex_動画制作スキル_コピペ用

動画制作を始める時は、長いルールを貼らない。
細かいルールは `AGENTS.md`、スキル、`00_全体管理/rules/` 側でCodexが読む。

このノートでは、毎回貼る文を短くする。
ただし、次の2つは運用で使うため消さない。

- `投稿情報を登録する時`
- `分析・解析`

週次分析後は、承認済みの改善点だけを `$anry-video-from-user-plan` の `latest-weekly-improvements.md` に3〜5個で反映する。
長い分析本文やKPI原文は毎回読ませない。
週次分析結果は `ANRYCAMPANY/YouTube分析/YYYY-MM-DD_YYYY-MM-DD_週次分析.md` に残す。
次に作る動画候補を出す時は、必ず `ANRYCAMPANY/投稿情報/投稿情報_一覧.md` と `ANRYCAMPANY/01_動画管理.md` を確認する。
既存投稿と同じ主語・同じ不安・同じ検査場面の案は出さない。
リメイク候補は今すぐ作る候補に混ぜず、後日枠に分ける。

## 使い分け

- Claude Code: 台本初稿、構成のたたき台。
- GPT-5.6: KPI確認、過去投稿との照合、軽量な改善案。
- GPT-5.5: 医療表現、誤解リスク、不安を煽らないかの最終確認。
- `$anry-video-production`: テーマからCodexに台本案・投稿情報案・画像構成案を提案してほしい時。
- `$anry-video-from-user-plan`: 台本案・画像構成案・キャラ案などをこちらで用意している時。

## 最短: テーマから始める

```text
$anry-video-production で、〇〇のリール制作を始めてください。
まず台本案・投稿情報案・画像構成案だけ出してください。
まだ画像・音声・動画は作らないでください。
```

## Claude Codeの初稿を確認する

```text
$anry-video-from-user-plan で確認してください。
以下はClaude Codeで作った台本初稿です。
内容を尊重して、必要な修正だけ提案してください。

確認してほしい点:
- 冒頭3秒
- 保存されやすさ
- CTA
- 尺
- 医療表現の違和感
- 患者さんの不安を煽っていないか
- 最新の週次改善点が反映できているか

まだ画像・音声・動画は作らないでください。

【ここに台本初稿を貼る】
```

## ユーザー案を確認する

```text
$anry-video-from-user-plan で確認してください。
以下の台本案・画像構成案を尊重して、必要な修正だけ提案してください。
最新の週次改善点も、必要な範囲で反映してください。
まだ画像・音声・動画は作らないでください。

【ここに案を貼る】
```

## キャラクターが出る時

```text
$anry-video-from-user-plan で確認してください。
人物が出ます。
character-rules.md、_character_quickref.md、_patient_clothing_index.md を確認してください。
Character IDノート全文は、画像生成直前か不明点がある時だけ確認してください。

まだ画像・音声・動画は作らないでください。

【ここに台本案・画像構成案を貼る】
```

## 画像に進む時

```text
承認済みの内容で、画像計画と1〜2枚の確認用フレームに進んでください。
まだ残り画像・テロップ・音声・動画は作らないでください。
```

## 残り画像に進む時

```text
確認用フレームOKです。
残りの画像に進んでください。
まだテロップ・音声・動画は作らないでください。
```

## テロップに進む時

```text
画像OKです。テロップ入力に進んでください。
テロップは要点だけにして、1画面あたり短く読みやすくしてください。
まだ音声・動画は作らないでください。
```

## テロップ文言を指定したい時

```text
画像OKです。テロップ入力に進んでください。

テロップ方針:
- 要点だけ
- 1画面1メッセージ
- X軸は中央に配置
- テロップ位置は「上・中央・下」の3パターンのみ
- 可能であれば全フレーム中央配置を優先
- 人物の頭・顔・髪にかかる場合だけ、上または下の中央配置に変更
- 余白を探して左右にずらさない
- 患者さん向けにやさしく
- 医療表現は断定しすぎない
- 重要語だけ強調する
- 青強調は文節全体ではなく、強調したい語だけに限定する

まだ音声・動画生成はしないでください。
```

## 音声・動画に進む時

```text
画像とテロップOKです。
音声と動画生成に進んでください。
画像と音声が合っているか確認してください。
また、おかしな「間」はつくらないようにしてください。
```

## 動画完成後: タイトル・説明・ハッシュタグ

```text
動画完成です。
タイトル、説明文、ハッシュタグをお願いします。
投稿メタ情報やハッシュタグに #ANRYCAMPANY は入れないでください。
```

## 途中から再開する時

```text
このリール制作を再開してください。
対象ノートまたは素材フォルダ: ここに貼る
次に必要な作業だけ提案してください。
```

## 分析・解析

この項目は消さない。

```text
週次分析
Obsidianの該当週のInstagram/YouTube分析データを確認して、動画改善に直結する形で分析してください。
Instagramはインスタ_週次結果metricool「20260830」として入っています
YouTubeはF:\ANRYCAMPANY\ANRYCAMPANY\YouTube分析に「2026-08-22_2026-08-29」に入っています。
MetricoolとYouTubeアナリティクスの集計期間が異なる場合は、混同せず別々に扱ってください。

見てほしい点:
- 伸びた動画
- 伸びなかった動画
- 冒頭3秒の改善点
- 保存されやすいテーマ
- CTAの改善点
- 次も使う型
- やめる型
- 次に作る動画候補
- 動画制作スキルの latest-weekly-improvements.md に反映すべき3〜5個の改善点

次に作る動画候補は、投稿情報一覧と動画管理にある過去投稿・予約済み投稿と被らないものだけにしてください。
既存投稿と同じ主語、同じ不安、同じ検査場面の案は出さないでください。
リメイク版は後々作る前提なので、今すぐ作る候補には入れないでください。
必要ならSNSや病院FAQなどをリサーチし、医療従事者側では見落としやすい患者さんの日常品・当日の迷い・家族の困りごとから新しい候補を出してください。

分析後、スキル更新用の短い改善メモ案も出してください。
分析結果をObsidianの週次分析ノートにも残してください。
```

## 週次改善メモをスキルへ反映する時

```text
承認済みの週次改善メモで、$anry-video-from-user-plan の latest-weekly-improvements.md を更新してください。
Obsidianの動画制作スキルコピペ用ノートも必要なら更新してください。
古い改善点は残さず、今週使う3〜5個だけにしてください。
```

## 最新の承認済み週次改善メモ

```markdown
Updated: 2026-08-30

- 冒頭1秒はテーマ名ではなく、患者さん・家族の心の声から始める。痛み・姿勢系は「どの動きが痛いか」を先に出す。
- 5秒以内に「今日の1行動」を置く。再生が出ても平均視聴が浅い動画は、結論と行動が遅い可能性を疑う。
- 近いテーマを連続させる時は、1秒目の差分を明確にする。「痛い姿勢」「横向き」「体をひねる」を同じ「我慢しない」だけで始めない。
- CTAは用途別に書く。痛み・姿勢系は検査中に伝え方を思い出す、家族付き添いは検査前日や受付前に家族で確認、痛み・結果系は診察前の症状整理に寄せる。
- 次回候補は投稿情報一覧と動画管理を確認し、既存投稿と同じ主語・同じ不安・同じ検査場面の案は出さない。リメイクは後日枠に分け、SNSや病院FAQから患者さんが日常品として見落としやすいものを拾う。
```

## 使い方のコツ

- 依頼文にルールを長く書かない。
- テーマ、対象ノート、素材フォルダ、今進めたい工程だけを書く。
- 台本全文を毎回貼り直さず、承認済みノートや素材フォルダを指定する。
- 画像、音声、動画へ進む時は「何がOK済みか」を短く書く。
- 人物が出る時は、Character全文ではなく `_character_quickref.md` と `_patient_clothing_index.md` を優先する。
- 投稿情報登録と分析・解析のコピペ欄は、運用に必要なので消さない。
- 台本確認で冒頭・保存・CTAを見る時は、最新の週次改善メモも確認させる。
- 次候補を出す時は、既存投稿・予約済み投稿と被らないかを先に確認させる。
- テロップで重要語だけ色を変える時は、生成前に「強調語だけが別セグメントか」を確認させる。`any(key in part for key in highlights)` のような包含判定だと、語を含む文節全体が青になる。
- 修正版のテロップや画像は、前回フォルダに混ぜず日付つきの専用フォルダに出力させる。

## 強制停止コマンド

```powershell
Get-Process python, ffmpeg -ErrorAction SilentlyContinue | Stop-Process -Force
```

VOICEVOXも含めて止めたい場合:

```powershell
Get-Process | Where-Object { $_.ProcessName -match 'VOICEVOX|run|python|ffmpeg' } | Stop-Process -Force
```
