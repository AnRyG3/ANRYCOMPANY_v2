# Codex_動画制作スキル_コピペ用

動画制作を始める時は、短い合図だけでよい。
細かいルールは `AGENTS.md`、スキル、`00_全体管理/rules/` 側で読む。

## 使い分け

- `$anry-video-production`: テーマからCodexに台本案・投稿情報案・画像構成案を提案してほしい時。
- `$anry-video-from-user-plan`: 台本案・画像構成案・キャラ案などをこちらで用意している時。

## テーマから始める

```text
$anry-video-production で、〇〇のリール制作を始めてください。
まず台本案・投稿情報案・画像構成案だけ出してください。
```

## ユーザー案を確認する

```text
$anry-video-from-user-plan で確認してください。
以下の台本案・画像構成案を尊重して、必要な修正だけ提案してください。
まだ画像・音声・動画は作らないでください。
```

## ユーザー案を貼る時

```text
$anry-video-from-user-plan で確認してください。
　
　
　
キャラクターID

人物が出る場合:
character-rules.md と _character_quickref.md を先に確認。
患者服装は _patient_clothing_index.md を優先。
Character IDノート全文は画像生成直前か不明点がある時だけ確認。

必要な修正だけ提案してください。
まだ画像・音声・動画は作らないでください。
```

## 画像に進む時

```text
承認済みの内容で、画像計画と1〜2枚の確認用フレームに進んでください。
```

## 残り画像に進む時

```text
確認用フレームOKです。残りの画像に進んでください。
```
## テロップに進む時

```text
画像OKです。テロップ入力に進んでください。
テロップは要点だけにして、1画面あたり短く読みやすくしてください。
```

### テロップ文言の指示を入れたい時

```text
画像OKです。テロップ入力に進んでください。

テロップ方針:
- 要点だけ
- 1画面1メッセージ
- 長文にしない
- 患者さん向けにやさしく
- 医療表現は断定しすぎない
- 重要語だけ強調する

まだ音声・動画生成はしないでください。
```

### もっと短く頼む時

```text
画像OKです。テロップ入力をお願いします。
文言は要点だけで、短く読みやすくしてください。
```

## 音声・動画に進む時

```text
画像OKです。音声と動画生成に進んでください。
```

## 動画完成　タイトル　説明　ハッシュタグ

```text
動画完成です。タイトル　説明　ハッシュタグをお願いします。
```


## 途中から再開する時

```text
このリール制作を再開してください。
対象ノートまたは素材フォルダ: ここに貼る
次に必要な作業だけ提案してください。
```

## 投稿情報を登録する時

```text
完成動画の投稿タイトル、説明文、ハッシュタグ、公開予約情報をObsidianに登録してください。
公開予約: 2026/MM/DD 19:00
URL: 
```

## 分析・解析

```text
週次分析
Obsidianの中に　インスタ*週次結果metricool　と　YouTube*週次結果metricool　入れています。
また、ANRYCAMPANYのYouTube分析の中に「2026-07-12_2026-07-18」としてYouTubeのアナリティクス詳細をいれています。　これらを取得して分析班に解析させてください
```
## 使い方のコツ

- 依頼文にルールを長く書かない。
- テーマ、対象ノート、素材フォルダ、今進めたい工程だけを書く。
- 台本全文を毎回貼り直さず、承認済みノートや素材フォルダを指定する。
- 画像、音声、動画へ進む時は「何がOK済みか」を短く書く。
- 人物が出る時は、Character全文ではなく `_character_quickref.md` と `_patient_clothing_index.md` を優先する。
## 強制停止コマンド

```powershell
Get-Process python, ffmpeg -ErrorAction SilentlyContinue | Stop-Process -Force
```

VOICEVOXも含めて止めたい場合:

```powershell
Get-Process | Where-Object { $_.ProcessName -match 'VOICEVOX|run|python|ffmpeg' } | Stop-Process -Force
```
