# Codex_動画制作スキル_コピペ用

動画制作を始める時は、下の文をそのままコピーしてCodexに送る。

## 使い分け

- `$anry-video-production`: テーマだけ渡して、Codex側に台本案・画像構成案から提案してほしい時に使う。
- `$anry-video-from-user-plan`: 台本案・画像構成案・キャラ案をこちらで用意していて、それを尊重して確認・制作してほしい時に使う。

---

## パターン1: テーマからCodexに提案してもらう時

```text
$anry-video-production を使ってください。ANRYCAMPANYのルール通り、Obsidian確認→台本提案→画像構成提案からお願いします。まだ画像・音声・動画は作らないでください。
```

## テーマを入れて依頼する時

```text
$anry-video-production を使ってください。ANRYCAMPANYのルール通り、Obsidian確認→台本提案→画像構成提案からお願いします。テーマは「ここにテーマを書く」です。まだ画像・音声・動画は作らないでください。
```

## パターン2: 台本案・画像構成案をこちらで用意している時

```text
$anry-video-from-user-plan を使ってください。台本案・画像構成案・キャラ案はこちらで用意しています。ANRYCAMPANYのルール通り、内容確認→必要な修正提案→画像制作前の確認からお願いします。まだ画像・音声・動画は作らないでください。
```

## ユーザー案ベースで、内容を貼って依頼する時

```text
$anry-video-from-user-plan を使ってください。

台本案:
ここに台本を貼る

画像構成案:
ここに画像構成を貼る

キャラ案:
ここにキャラクターIDや服装指定を貼る

ANRYCAMPANYのルール通り、内容確認→必要な修正提案→画像制作前の確認からお願いします。まだ画像・音声・動画は作らないでください。
```

## ユーザー案ベースで、画像制作へ進む時

```text
$anry-video-from-user-plan を使って、この台本案・画像構成案のまま画像制作へ進めてください。ANRYCAMPANYのルール通り、登録キャラクターと素材を確認してから作成してください。
```

## 途中から再開する時

```text
$anry-video-production を使って、この動画制作の続きを進めてください。現在の素材、台本、投稿情報を確認してから、次に必要な作業だけ提案してください。
```

## 投稿情報を登録する時

```text
$anry-video-production を使って、完成動画の投稿タイトル、説明文、ハッシュタグ、公開予約情報をObsidianに登録してください。公開予約は YYYY/MM/DD 19:00、URLは ここに貼る。
```

## 注意

- 最初は「台本提案」と「画像構成提案」まで。
- ユーザー案がある時は、勝手に大きく作り替えず、必要な修正だけ提案する。
- CTAや推奨事項など、ユーザーが入れた重要ポイントは黙って省かない。
- 画像、音声、動画は承認後に進める。
- 人物画像は登録キャラクターだけ使う。
- 音声読みは、骨密度=こつみつど、DXA=できさ、乳房=にゅうぼう、値=あたい。
