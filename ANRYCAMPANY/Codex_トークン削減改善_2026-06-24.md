# Codex トークン削減改善 2026-06-24

## 目的

ANRYCAMPANY_v2のリール制作で、品質を維持しながらCodexのトークン消費を減らし、制作開始から提案までの速度を上げる。

## 実施内容

- `AGENTS.md` を短縮し、毎回必要な絶対ルールだけに整理した。
- `00_全体管理/Codex_最初に読む.md` を短縮し、詳細ルールの重複を外した。
- リール制作ルールを `00_全体管理/rules/` に段階別で分離した。
- `$anry-video-production` と `$anry-video-from-user-plan` のスキル本文を短縮した。
- 動画制作スキル使用方法ノートへの常時参照を外した。

## 新しい参照構成

常時読む入口:

- `README.md`
- `AGENTS.md`
- `00_全体管理/Codex_最初に読む.md`

リール制作時に読む:

- `00_全体管理/rules/reel-core.md`

必要時だけ読む:

- 人物画像: `00_全体管理/rules/character-rules.md`
- 音声、ナレーション読み: `00_全体管理/rules/voice-rules.md`
- 投稿情報: `00_全体管理/rules/posting-info-rules.md`
- 完成報告: `00_全体管理/rules/final-checklist.md`
- 会社全体の運用相談: `00_全体管理/ANRYCAMPANY_毎日運用マニュアル.md`

## 維持した重要ルール

- 「動画制作開始」と言われても、最初は台本案、投稿情報案、画像構成案までにする。
- 画像、音声、動画、生成スクリプトは、ユーザーの明確な承認後に進める。
- ナレーションは原則500字前後にする。
- 画像構成はCTA込みで原則10枚前後にする。
- 音声速度は1.2x固定にする。
- 画像はリアルな臨床場面、装置、人物、検査室を優先する。
- 人物画像は登録済みCharacter IDだけを使う。
- 新規作成文では必ず「診療放射線技師」を使う。
- 投稿メタ情報やハッシュタグに `#ANRYCAMPANY` は入れない。

## 推定削減効果

- `AGENTS.md`: 約2,890トークン相当から約1,487トークン相当に削減。
- `Codex_最初に読む.md`: 約1,448トークン相当から約987トークン相当に削減。
- `anry-video-production` スキル: 約1,839トークン相当から約1,176トークン相当に削減。
- `anry-video-from-user-plan` スキル: 約1,903トークン相当から約1,202トークン相当に削減。

リール初回提案時は、従来比で約25〜40%の削減見込み。
音声、投稿情報、完成チェック、キャラクター確認は必要時だけ読む構成にしたため、工程ごとの読み込みも軽くなる見込み。

## 今後の運用

- 重要な絶対ルールは `AGENTS.md` か `00_全体管理/rules/` に置く。
- スキル本文には長いルールを重複させず、どの段階で何を読むかだけを書く。
- 日本語ノートを追加・更新する時は、UTF-8 BOM付きで保存して読み取りを安定させる。
- 新しいルールを追加する時は、常時必要か、リール制作時だけか、音声・投稿・完成確認などの必要時だけかを分けて保存する。

## 2026-06-24 追加対応

スキル依頼文のトークンをさらに減らすため、Obsidianのコピペ用ノートを短縮版へ上書きした。

変更内容:

- `ANRYCAMPANY/Codex_動画制作スキル_コピペ用.md` を短縮版に更新。
- `00_全体管理/Codex_動画制作スキル使用方法.md` はObsidian側ノートへの案内と最短依頼だけに整理。
- `ANRYCAMPANY/99_Codex依頼メモ.md` の旧人物作成メモを `ANRYCAMPANY/アーカイブ/2026-06-24_旧_動画用人物作成メモ.md` へ退避。

今後の依頼は「スキル名、テーマまたは対象ノート、今進めたい工程」だけを書く。

## 2026-06-29 追加対応

初回提案時に不要なテロップ詳細を遅延参照へ変更した。

変更内容:

- `AGENTS.md` からテロップ安全域・フォント指定の詳細を外した。
- `00_全体管理/rules/reel-core.md` からテロップ詳細を外した。
- `00_全体管理/rules/telop-style-rules.md` を新設し、文字入れ・最終テキスト画像生成時だけ読む構成にした。
- 完成動画OK後の投稿文提示ルールを `posting-info-rules.md` 側へ移した。
- `anry-video-production` と `anry-video-from-user-plan` のスキル本文を上書きし、毎回読む説明を最小化した。
- スキル内の文字化けしていた日本語パスを正しいUTF-8表記に修正した。

推定効果:

- リール初回提案時に約300〜500トークン削減。
- スキル本文の読み込みは、1スキルあたり約500〜700トークン削減。
- 画像・文字入れ段階では品質維持のため `telop-style-rules.md` を読む。

確認:

- `git diff --check` は問題なし。
- スキルの `name` と `description` を含むフロントマター形式を確認済み。
- ワークスペース内の今回変更したMarkdownはUTF-8 BOM付きにそろえた。
