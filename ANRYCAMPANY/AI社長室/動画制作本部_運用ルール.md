# 動画制作本部 運用ルール

## 目的

放射線技師の安心ラボのリール、YouTube Shorts、TikTokを継続的に作る。
一般の人の不安を安心に変え、保存される投稿を増やす。

## 必須チーム

動画制作では、分析AIを必ず参加させる。

分析AIは投稿後だけでなく、次の3回入る。

1. 企画前
2. 台本改善時
3. 投稿後

分析なしで台本を確定しない。
分析なしで120点台本と呼ばない。

## 制作フロー

1. [[01_動画管理]] を確認する
2. 過去投稿、保存率、反応、勝ちパターンを確認する
3. 企画案を作る
4. 分析AIが「伸びる理由」と「弱い理由」を見る
5. 台本のたたき台を作る
6. 10項目で採点する
7. 100点台本へ改善する
8. 分析AIが保存価値、冒頭3秒、離脱ポイントを見る
9. 120点台本へ改善する
10. 医療表現チェックをする
11. 社長に提出する
12. 社長のOK後に、画像、音声、動画、投稿情報へ進む
13. 投稿後に分析し、次回台本へ反映する

## 完成動画承認後の自動提示

社長から完成動画に対して、次のような承認表現があった場合は、追加の依頼を待たずに投稿用情報をチャットへ提示する。

- 「動画OKです」
- 「動画OK」
- 「これでOK」
- 「採用」
- 「問題ありません」
- その他、完成動画を承認したと判断できる表現

提示する順番は固定する。

```text
投稿タイトル
説明文
ハッシュタグ
```

承認が比較用動画への感想なのか、正式採用なのか判断できない場合は、正式ファイルへの上書きや公開予約は行わない。
ただし、投稿タイトル・説明文・ハッシュタグは確認用として提示してよい。

## 台本工程

```text
たたき台
↓
100点台本
↓
分析AIチェック
↓
120点台本
↓
医療表現チェック
↓
社長確認
```

## 採点項目

各10点、合計100点で見る。

| 項目 | 見ること |
|---|---|
| フック | 3秒以内に見たいと思えるか |
| 分かりやすさ | 一般の人に伝わる言葉か |
| 驚き | え？と思う要素があるか |
| 保存価値 | 後で見返したくなるか |
| 共感 | 不安や経験に寄り添えているか |
| 専門性 | 放射線技師視点があるか |
| 安心感 | 最後に不安が下がるか |
| テンポ | 1文が短く流れがよいか |
| コメント | 問いかけが自然か |
| 完走率 | 最後まで見たくなるか |

## 120点ボーナス

100点満点に加えて、次の要素が強い場合は最大20点を加点する。

| ボーナス | 最大点 |
|---|---:|
| 最初の1秒が強い | +5 |
| 保存したくなる実用性が高い | +5 |
| 放射線技師だから言える現場感がある | +5 |
| コメントが生まれやすい問いがある | +5 |

## 動画制作で必ず守ること

- 制作に入る前に、必ず台本を社長へ提出する
- 台本確認では、医療従事者目線と患者目線のズレを確認する
- 台本と画像は1枚1文・1メッセージで作成する
- 音声の基本話速は、動画の長さにかかわらず `1.20倍` とする
- `50秒` を境に話速を切り替える運用は行わない
- 声優の変更や聞き取りにくさがある場合は、その都度、話速や台本を個別に調整する
- 同じ動画内で登場する人物は、容姿・髪型・服装・服の色を統一する
- シリーズ動画では、ユーザー指定の参照モデルを使い、患者さんの人物設定をシリーズ全体で統一する
- 参照モデルの指定がない場合は、画像生成前にユーザーへ確認する
- 別シリーズや続編では、前回の人物設定を自動で引き継がない
- 全体は原則10〜12枚で作成する
- 医療表現は断定しすぎない
- 不安をあおりすぎない
- 最後は安心感で終える
- 最後の2枚にCTAを入れる
- ラスト2枚目は固定案内文「検査前の不安を / 安心に変える情報を発信中」にする
- ラスト1枚は保存CTAにする
- 次回予告を入れる
- 投稿タイトル、説明文、ハッシュタグは投稿情報フォルダへ保存する
- 完成動画が承認されたら、投稿タイトル、説明文、ハッシュタグをチャットにも自動提示する

## マンモグラフィー動画の監修表記

- 「マンモグラフィー認定技師 監修済み」は、マンモグラフィー関連動画だけに入れる。
- CT、MRI、エコー、レントゲン、検査前シリーズなど、他の動画へ自動適用しない。
- マンモグラフィー関連動画でも、実際に監修確認が完了した動画だけに入れる。
- 動画内では固定CTAの直前に1枚追加する。
- 概要欄では1行目または2行目に記載する。
