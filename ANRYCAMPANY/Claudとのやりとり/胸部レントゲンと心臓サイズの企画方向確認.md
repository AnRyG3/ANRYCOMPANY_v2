**保護者の不安の順番で並べる案**

1. **抱っこして付き添っても大丈夫？** → 検査前、まず親が知りたい実務的な疑問（入口として自然）
2. **泣いている子、無理やり撮影するの？** → 検査中の不安（うちの子は大丈夫かな）
3. **動いてしまう子どもの検査、実際どうしてるの？** → 検査中のより具体的な疑問（②と近いので直後に）
4. **小さい子でも被ばくは大丈夫？** → 検査後・全体を通しての疑問（数値を出さず「配慮している」の軸でまとめ的に締める）

流れとしては「検査前→検査中→検査中（具体）→検査全体を通しての安心」という保護者の時系列に沿わせています。

その視点、④の内容に活かせそうです。「小さい子でも被ばくは大丈夫？」の回、数値は出さない方針なので、電圧・電流・タイマーをそのまま説明すると専門的になりすぎますが、\*\*「小さい子には、小さい子に合わせた設定に調整して撮っています」\*\*くらいの表現に落とし込むと、専門知識に裏付けられた安心感を出せそうです。

- 「小さい子には、小さい子に合わせた条件で撮影しています」
- 「体格に合わせて、必要な分だけで済むよう調整しています」

数値も専門用語も出さずに、「ちゃんと配慮されている」という事実だけを伝える形です。
