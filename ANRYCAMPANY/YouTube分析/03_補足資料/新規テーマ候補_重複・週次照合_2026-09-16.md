## 今すぐ作る候補

### ⑥ 検査の予約時間に遅れそう。まずどこへ連絡する？

- 主語: 検査へ向かっている本人、または送迎中の家族
- 不安: 遅刻したら検査を断られるのか、向かわない方がよいのか、迷惑ではないか
- 場面: 予約票を見ながら病院へ向かう途中
- 1秒目の心の声: `あと10分。予約時間に間に合わない…`
- 3秒以内の暫定結論: `自己判断で行くのをやめず、まず予約票の連絡先へ電話を。`
- 続ける情報: `検査名・予約時刻・到着見込み` の3点を伝える
- 施設差: 検査内容や予約枠で対応が異なるため、`そのまま来院できる`、`時刻変更`、`再予約` を断定しない
- CTA: `予約票と一緒に、当日の連絡メモとして保存`

### 週次との相性

- 物の名前だけに頼らず、`受けられるか + 次に取る行動` が明確。
- 本人と送迎家族の両方が自分ごと化できる。
- `受付前・来院途中` の1場面1行動に絞れる。
- MRI小物、マンモ、腹部エコーと画面が重ならない。
- 検索語として `検査 予約 遅刻`、`病院 検査 遅れそう` を自然に残せる。

## 追加する4候補

### 1. 検査着に着替えたら寒い。毛布をお願いしていい？

- 主語: 検査着で待機・撮影する本人
- 不安: 寒くても検査の邪魔になると思い、我慢すべきか迷う
- 場面: 更衣後の待合または検査台に横になる直前
- 1秒目の心の声: `検査着、寒い。でも言っていいの？`
- 3秒以内の暫定結論案: `我慢せず、検査前にスタッフへ伝えてください。対応方法は検査ごとに確認します。`
- CTA: `寒がりな家族にも共有`
- 重複しない理由: 既存の検査着動画は着替える理由・下着・羞恥心が主題で、寒さを我慢する不安は扱っていない。
- 確認事項: 当院で貸せるもの、持参上着の扱い、検査中に使える保温方法を制作前に確認する。
- 参考: [岩手医科大学附属病院の患者意見への回答](https://www.hosp.iwate-med.ac.jp/yahaba/faq/faq-r6m6/) には、薄い病衣で寒かったという患者側の具体的な困りごとが掲載されている。

### 2. 造影CTの注射、利き腕にしてもいい？

- 主語: 造影CTを受ける本人
- 不安: 検査後に運転・仕事・家事があるため、利き腕への注射を避けられるか、逆に血管が見える利き腕を希望してよいか
- 場面: 造影剤の注入路を確保する前
- 1秒目の心の声: `注射、利き腕でも大丈夫？`
- 3秒以内の暫定結論案: `希望や過去の採血で困ったことは、針を刺す前に伝えてください。刺す側は検査内容と血管の状態を見て決めます。`
- CTA: `造影CTの受付で伝えるメモとして保存`
- 重複しない理由: 既存の造影CT動画は飲食・薬・授乳・検査後症状が中心で、注射する腕の希望と当日の生活は扱っていない。
- 確認事項: 当院で左右を選ぶ基準、手術歴や治療歴の聞き取り、患者希望を伝えるタイミングを制作前に確認する。
- 参考: [日本放射線技術学会のCT解説](https://www.jsrt.or.jp/data/citizen/housya/ct-01/) と [国立がん研究センター中央病院のCT案内](https://www.ncc.go.jp/jp/ncch/division/radiological_technology/radiological_diagnosis/xsenkensa/030/030.html) は、造影剤を腕の静脈から投与すると案内している。左右の一律回答は置かない。

### 3. 胸のレントゲン、長い髪はどこまで結べばいい？

- 主語: 肩より長い髪で胸部X線撮影を受ける本人
- 不安: 低い位置で結ぶだけでよいか、髪が写って撮り直しにならないか
- 場面: 撮影室へ入る直前の身支度
- 1秒目の心の声: `髪は結んだ。でも、この位置で大丈夫？`
- 3秒以内の暫定結論案: `肩や背中に髪がかからない位置へまとめます。迷ったら撮影前に確認してください。`
- CTA: `健診前日の持ち物メモに、ヘアゴムを追加`
- 重複しない理由: 既存の胸部X線動画は息止めや服装が中心で、長い髪とヘアゴムは扱っていない。
- 確認事項: 当院で案内する結ぶ位置、ヘアピン等の扱い、ヘアゴムを忘れた場合の対応を制作前に確認する。
- 参考: [釧路市医師会健診センター](https://www.kushiro-ishikai.or.jp/kensin/99_blank082.html) と [北星学園大学の2026年度胸部レントゲン案内](https://cgw.hokusei.ac.jp/hgu/wp-content/uploads/2026/02/2026%E5%B9%B4%E5%BA%A6-%E8%83%B8%E9%83%A8%E3%83%AC%E3%83%B3%E3%83%88%E3%82%B2%E3%83%B3%E6%92%AE%E5%BD%B1%E3%81%AE%E6%B3%A8%E6%84%8F%E2%91%A0%E2%91%A1.pdf) は、長い髪を肩にかからないようまとめる案内を掲載している。

### 4. 骨密度検査の日、タイツや補正下着は脱ぐ？

- 主語: タイツ・ストッキング・補正下着で来院した本人
- 不安: そのまま測れるのか、更衣が必要なら何を着て行けばよいか
- 場面: 骨密度検査の更衣前
- 1秒目の心の声: `骨密度って、タイツも脱ぐの？`
- 3秒以内の暫定結論案: `測る部位と衣類の素材で対応が変わるため、脱ぎ着しやすい服で行き、当日の案内を確認してください。`
- CTA: `骨密度検査の服装メモとして保存`
- 重複しない理由: 既存の骨密度動画は検査の目的や結果が中心で、タイツ・補正下着という当日の服装は扱っていない。
- 確認事項: 当院の測定部位、着替えが必要な衣類、検査着の有無を制作前に確認する。
- 参考: [伊奈病院の骨密度検査案内](https://www.inahp.saitama.jp/department/radiology/bmd.php) は、腰椎・股関節に重なる金属やプラスチック、衣類により着替えが必要になる場合があると案内している。

## 保留候補

### ⑧ MRIの日、ヒートテックは脱ぐ？

- 未投稿で、患者さん語としての需要は確認できる。
- ただし直近のMRI小物シリーズは、再生入口は強くても保持率が低い。メイク987回・7.9%、カラコン924回・9.5%。
- 少なくとも別検査・別場面の動画を2〜4本挟み、秋冬に再判定する。
- 制作時は `ヒートテックなら一律` と製品名で断定せず、`機能性インナーは素材や加工、施設案内で対応が異なるため予約先へ確認` とする。

## 全体の優先順位

今すぐ検討する5案の暫定順:

1. `検査の予約時間に遅れそう。まずどこへ連絡する？`
2. `検査着に着替えたら寒い。毛布をお願いしていい？`
3. `胸のレントゲン、長い髪はどこまで結べばいい？`
4. `造影CTの注射、利き腕にしてもいい？`
5. `骨密度検査の日、タイツや補正下着は脱ぐ？`

`MRIの日、ヒートテックは脱ぐ？` はこの5案には含めず、秋冬・MRI間隔確保後の保留候補とする。

## 分析班への申し送り

- 新規テーマ候補を出す前に、[[投稿情報/投稿情報_一覧]] と [[01_動画管理]] を必ず検索する。
- タイトルが違っても、主語・不安・検査場面・視聴後の行動が同じなら重複扱いにする。
- 既存動画の入口が強く保持が弱い場合、新テーマとして出し直さず `冒頭3秒を改善するリメイク候補` へ分ける。
- 次回週次では、⑥を `来院途中の行動テーマ`、追加4案を `寒さ・注射する腕・髪・服装` の日常行動テーマとして比較する。
- 当院で扱わないPET/CT・骨シンチは候補化しない。バリウム検査後の帰路とマンモグラフィ当日の制汗剤は2026-09-23・09-24に公開予約済みのため、新規候補へ戻さない。
