# YouTube分析 取得項目ルール

## 結論

YouTube Studioのアナリティクスは、毎回すべて取得しなくてよい。

通常の週次分析では、動画改善に直結する項目だけを取得する。月1回だけ、チャンネル全体の発見経路、新規視聴者、視聴者属性を確認する。細かい項目は、必要なテーマが出た時だけ取得する。

YouTube分析の主データは、今後はYouTube Studioに寄せる。Metricoolは集計期間や個別動画データが読み取りにくいため、YouTubeの動画別分析では原則使わない。

## 週次で必要なもの

週次分析の目的は、次に作る動画を決めること。

以下を取得する。

| 項目 | 使い道 |
|---|---|
| コンテンツ | 伸びた動画、伸びなかった動画、平均視聴時間、登録者増を確認する |
| 日付 | 週内の山、投稿直後の反応、曜日ごとの動きを確認する |
| トラフィック ソース | ショートフィード、検索、ブラウジングの割合を確認する |
| 新しい視聴者とリピーター | 新規に届いているか、戻ってきている人がいるかを見る |
| 視聴行動別の視聴者区分 | 新しい視聴者、ライトな視聴者などの反応を見る |
| チャンネル登録元 | どの流入が登録につながったかを見る |

週次では、この6項目を優先する。

判断すること:

- 伸びた動画
- 伸びなかった動画
- 冒頭3秒の改善点
- 次も使う型
- やめる型
- 次に作る動画候補

## 月1で必要なもの

月次分析の目的は、チャンネル全体の方向性を確認すること。

以下を月1回、直近28日間または月間で取得する。

| 項目 | 使い道 |
|---|---|
| トラフィック ソース | チャンネル全体の発見経路を確認する |
| 新しい視聴者とリピーター | 新規視聴者、ユニーク視聴者、リピーター傾向を見る |
| 視聴者の年齢 | 誰に届いているかを確認する |
| 視聴者の性別 | テーマや表現の方向性を確認する |
| 地域 | 国内中心か、海外流入があるかを見る |
| デバイスのタイプ | スマホ中心か、タブレットやテレビ視聴があるかを見る |
| YouTube サービス | Shorts中心か、通常動画や他サービス経由があるかを見る |
| コンテンツ タイプ | ショート、動画、ライブなどの比率を見る |
| 再生場所 | ショートフィード、チャンネルページ、埋め込みなどを見る |

月次で確認すること:

- チャンネル全体の発見経路
- 新しい視聴者数
- ユニーク視聴者数
- リピーター数
- ショートフィード依存の強さ
- YouTube検索の伸び
- 視聴者属性の変化

## 必要時だけでいいもの

通常の週次分析では優先度が低い。

| 項目 | 取得するタイミング |
|---|---|
| OS | 表示崩れや端末差を疑う時 |
| 都市 | 地域性の強い企画を考える時 |
| 字幕 | 字幕運用や無音視聴を検証する時 |
| 音声トラック | 多言語音声や音声差し替えを使う時 |
| 動画の情報の言語 | 海外向け、翻訳運用を考える時 |
| 翻訳版の使用 | 翻訳版を本格運用する時 |
| 終了画面要素 | 長尺動画や終了画面導線を改善する時 |
| 終了画面要素タイプ | 終了画面の種類別に比較したい時 |
| 再生リスト | 再生リスト導線を作った後 |
| 投稿 | YouTubeコミュニティ投稿を使った時 |
| オーガニック トラフィックと有料のトラフィック | 広告や有料施策を使った時 |

## 2026-08-02時点の判断

直近28日間の分析では、発見経路はショートフィードが中心。

| 指標 | 数値 |
|---|---:|
| ショートフィード | 13,217回、89.5% |
| YouTube検索 | 1,235回、8.4% |
| ブラウジング機能 | 147回、1.0% |
| 新しい視聴者 | 4,191人 |
| ユニーク視聴者数 | 4,920人 |
| リピーター | 122人 |

このため、当面の週次分析はショートフィードで止められる冒頭1〜3秒、平均視聴時間、登録者増を優先して見る。

検索流入も約8%あるため、タイトルと説明欄には患者さんが検索しそうな言葉を入れる。

例:

- レントゲン
- CT
- MRI
- 造影剤
- 検査前
- 検査後
- 副作用
- 絶食
- 骨折
- 検査中に動いた

## 運用メモ

- 週次は厳選6項目でよい。
- 月1回は直近28日間データを取得する。
- YouTube分析は、原則YouTube Studioを正データとして扱う。
- MetricoolとYouTube Studioは集計期間がずれるため、同じ表で混ぜない。
- YouTube Metricoolは、全体確認の参考にとどめ、動画別勝敗には使わない。
- 個別動画の勝敗は、原則YouTube Studioの `コンテンツ` を優先する。
- Instagram Metricoolは、リール別の再生数、リーチ、保存数、シェアがない場合、動画別勝敗を断定しない。
