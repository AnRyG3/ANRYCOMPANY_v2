# Character Quick Reference

リール制作時は、人物の初期確認にこの短縮版を優先する。詳細な顔・禁止事項・保存画像が必要な場合だけ各Character IDノートを読む。

## Common Rules

- 登録済みCharacter IDだけを使う。
- 実在人物、有名人、読める病院名、読める氏名、読めるID文字は使わない。
- 医療者と患者の職種・立場を混同しない。
- 新規日本語テキストでは必ず「診療放射線技師」を使う。

## When To Read Full Notes

- 新しい画像を生成する直前。
- 顔、髪型、服装、禁止事項で迷う場合。
- 既存の基準画像や表情差分を直接参照する場合。
- ユーザーが特定のCharacter IDを指定し、細部の一貫性が重要な場合。
