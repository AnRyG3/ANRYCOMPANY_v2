# Codex依頼メモ

Codexに見てもらいたいことをここに書く。

## 依頼テンプレート

```md
## 依頼タイトル

やりたいこと:
対象ファイル:
参考メモ:
困っていること:
希望する出力:
```

## すぐ頼みたいこと

- 制作メモと各管理メモを読んで、次に作るショート動画案を出す
- 申請中のLINEスタンプ2つの確認メモを整理する
- ブログの追加テーマを考える

## Codexへの頼み方

このチャットでこう頼む。

```text
Obsidianの AI社長室 を読んで、ANRYCAMPANY社長室AIとして進めて
```

```text
Obsidianの 99_Codex依頼メモ.md を読んで、次にやることを整理して
```

または、

```text

```
