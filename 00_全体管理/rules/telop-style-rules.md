# ANRYCAMPANY Telop Style Rules

Use this file only before image text insertion, final text-frame generation, or visual QA for text frames.

## Safe Area

- Instagram reels hide text near the very top, bottom, and right edge.
- Place the main telop inside the safe area, lower than the top UI zone and away from the right-side action icons.
- Do not place telop backing at the absolute top of the frame. Use a visibly lower top margin.

## Text Backing

- Use a white rounded rectangle backing at 85%-95% opacity.
- Use dark navy text for telops.
- Avoid pale blue, thin gray, or low-contrast text.

## Fonts

- Use only M PLUS Rounded 1c Bold for all telops.
- Available local M PLUS Rounded 1c font path: `F:\ANRYCAMPANY\reel_assets\fonts\M_PLUS_Rounded_1c\MPLUSRounded1c-Bold.ttf`.
- Do not use Noto Sans JP or any other font for telops unless the user explicitly asks.
- Do not thicken telop text with overdraw or duplicate drawing. Match apparent weight by font weight.
