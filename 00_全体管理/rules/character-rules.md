# ANRYCAMPANY Character Rules

Use this file before proposing or generating any person image for ANRYCAMPANY reels, samples, thumbnails, or video assets.

- Before generating any person image, also read `F:\ANRYCAMPANY\00_全体管理\rules\character-generation-gate.md` and follow it as a hard gate.
- Use only registered characters under `F:\ANRYCAMPANY\ANRYCAMPANY\Characters\`.
- For planning and quick checks, read `F:\ANRYCAMPANY\ANRYCAMPANY\Characters\_character_quickref.md` first instead of full Character ID notes.
- For patient clothing, read `F:\ANRYCAMPANY\ANRYCAMPANY\Characters\_patient_clothing_index.md` first.
- Read the full relevant Character ID note only before actual image generation, when details are ambiguous, or when the quick reference is insufficient.
- Before generating a person image, identify the Character ID, clothing source, and prohibited clothing.
- Before generating a person image, include the registered character reference image(s) whenever available; do not rely on text description alone for an existing Character ID.
- Put the Character ID and "same registered person, no new person, no substitute face" requirement at the top of every image prompt that contains a person.
- For patient characters, specify the age group and either the season clothing reference or the approved examination gown before generation.
- Do not invent, generate, or substitute a new person.
- Do not create an unregistered doctor, nurse, patient, healthcare worker, or background person unless the user explicitly approves creating a new Character ID first.
- Maintain the registered character's face, age range, hairstyle, body type, clothing rules, role, and prohibited items.
- If a generated sample visibly changes the registered character's face, age range, hairstyle, body type, or required clothing, treat it as a failed frame and stop before producing the remaining set.
- Do not approve a sample frame as "using the existing character" unless it visually matches the registered Character ID reference.
- If no registered character fits the scene, stop and ask whether to create a new Character ID before generating an image.
- This applies to sample frames, draft images, thumbnails, background people, and final video assets.
