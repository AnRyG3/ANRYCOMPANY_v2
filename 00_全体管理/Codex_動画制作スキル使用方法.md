# Codex_動画制作スキル使用方法

ANRYCAMPANYの動画制作を始める時は、内容に合わせてCodexスキルを使い分ける。

- `$anry-video-production`: テーマだけ渡して、Codex側に台本案・画像構成案から提案してほしい時に使う。
- `$anry-video-from-user-plan`: 台本案・画像構成案・キャラ案をこちらで用意していて、それを尊重して確認・制作してほしい時に使う。

## パターン1: テーマからCodexに提案してもらう時

そのまま使う場合は、次の文言を使う。

```
$anry-video-production を使ってください。ANRYCAMPANYのルール通り、Obsidian確認→台本提案→画像構成提案からお願いします。まだ画像・音声・動画は作らないでください。
```

テーマを指定する場合は、次の文言を使う。

```
$anry-video-production を使って、動画制作を始めてください。
テーマは「ここにテーマを書く」です。
Obsidianを確認して、まず台本と画像構成の提案だけ出してください。
まだ画像・音声・動画は作らないでください。
```

## パターン2: 台本案・画像構成案をこちらで用意している時

台本案、画像構成案、キャラ案をこちらで用意している場合は、次の文言を使う。

```
$anry-video-from-user-plan を使ってください。台本案・画像構成案・キャラ案はこちらで用意しています。ANRYCAMPANYのルール通り、内容確認→必要な修正提案→画像制作前の確認からお願いします。まだ画像・音声・動画は作らないでください。
```

内容を貼って依頼する場合は、次の形を使う。

```
$anry-video-from-user-plan を使ってください。

台本案:
ここに台本を貼る

画像構成案:
ここに画像構成を貼る

キャラ案:
ここにキャラクターIDや服装指定を貼る

ANRYCAMPANYのルール通り、内容確認→必要な修正提案→画像制作前の確認からお願いします。まだ画像・音声・動画は作らないでください。
```

ユーザー案ベースで画像制作へ進む場合は、次の文言を使う。

```
$anry-video-from-user-plan を使って、この台本案・画像構成案のまま画像制作へ進めてください。ANRYCAMPANYのルール通り、登録キャラクターと素材を確認してから作成してください。
```

## 短い指示

```
$anry-video-production で、〇〇の動画制作を始めてください。
```

## 途中から再開する時

```
$anry-video-production を使って、この動画制作の続きを進めてください。
現在の素材、台本、投稿情報を確認してから、次に必要な作業だけ提案してください。
```

## 完成後の投稿情報登録

```
$anry-video-production を使って、完成動画の投稿タイトル、説明文、ハッシュタグ、公開予約情報をObsidianに登録してください。
公開予約は YYYY/MM/DD HH:MM、URLは ここに貼る。
```

## このスキルに任せること

- Obsidian確認
- 台本提案
- 画像構成提案
- ユーザー案の内容確認
- ユーザー案の必要最小限の修正提案
- 登録キャラクター確認
- 読み間違い対策
- 画像と音声の同期確認
- 完成動画チェック
- 投稿タイトル、説明文、ハッシュタグ作成
- 公開予約URLの記録

## 注意

- 「動画制作を始めて」と言われても、最初は提案だけにする。
- ユーザー案がある時は、勝手に大きく作り替えず、必要な修正だけ提案する。
- CTAや推奨事項など、ユーザーが入れた重要ポイントは黙って省かない。
- 画像、音声、動画生成はユーザー承認後に進める。
- 人物画像は `ANRYCAMPANY/Characters/` の登録キャラクターだけ使う。
- 音声では読み間違いしやすい語をひらがなにする。
  - 骨密度: こつみつど
  - DXA: できさ
  - 乳房: にゅうぼう
  - 値: あたい
- 医療系の表現では、不安を強める言葉や断定を避ける。
