# LINE特集「夏を感じるスタンプ」あんりぃ40 制作方針

## 結論

今回の夏スタンプは、背景を盛る方向ではなく、あんりぃ本体のキャラ固定を最優先にする。

- あんりぃ本体は既存ベース画像から切り抜き、または既存あんりぃイラストを固定して使う
- 犬本体を生成AIで毎回描き直さない
- 夏感は「文字デザイン」「高品質な小物」「最小限のあしらい」で出す
- 背景は原則なし。入れる場合も薄い影、光、波線、冷感ドット程度に抑える
- 商品として買いたくなる、使いやすい一言を優先する

## 今回の失敗からのルール

### NG

- Geminiなどで9枚まとめて犬本体を生成する
- 耳、目、鼻、毛量、体型が変わる構図
- 別犬に見えるデフォルメ
- 背景を主役にする
- 安い夏アイコンを貼っただけの装飾
- 小物が平面的、低解像度、フリー素材感が強い
- 文字が読みにくい、または小さい画面で潰れる

### OK

- ベース画像の表情・顔つき・毛並みを保つ
- 同じあんりぃに、文字と小物だけを足す
- 背景なし、または透明背景に近い仕上げ
- 1スタンプにつき主役は「顔」「一言」「小物1つ」まで
- 夏小物は別生成、別素材化してから合成する
- 文字は太く、読みやすく、少し高級感のある手描き風にする

## 制作方式

### A案: 最優先

既存あんりぃ本体を固定し、40個の文字と小物だけを合成する。

- キャラ崩れが最も少ない
- LINEスタンプとして統一感が出る
- 量産しやすい
- 夏感は文字の色、縁取り、質感、小物で作る

### B案: 必要時だけ

高品質な夏小物だけを生成し、あんりぃ本体に合成する。

生成する小物例:

- 麦わら帽子
- ひまわり
- うちわ
- かき氷
- アイス
- スイカ
- ラムネ
- 浮き輪
- 風鈴
- 冷たいグラス

小物生成ルール:

- 小物だけを生成する
- 犬は描かない
- 透明背景または切り抜きやすい白背景
- 立体感、影、質感を重視
- チープな絵文字風は禁止

## あんりぃ固定ルール

- 顔: 丸い目、やさしい表情、少し控えめな口元
- 毛: ふわふわのクリーム色、耳まわりの毛量を保つ
- 体型: 小さめチワワ、頭が大きく見えるかわいさ
- 印象: やさしい、癒やされる、女性向け、日常で何度も使える
- 首元のアクセントは、既存の雰囲気を崩さない範囲で残す

## 文字デザイン方針

背景より文字で買いたくなる品質を作る。

- 太めで丸い日本語フォント
- 白フチ、濃い影、淡い夏色の差し色
- 文字は2から6文字を中心にする
- 長文は避ける
- 「夏だけ」ではなく日常返信にも使える言葉を多めにする

推奨カラー:

- 白フチ
- 深いブラウン影
- ひまわりイエロー
- ラムネブルー
- スイカレッド
- ミントグリーン
- 夕焼けピンク

## 試作順

最初から40個を作らず、まず5個だけで品質判定する。

1. あついね
2. 水分とってね
3. おつかれ
4. ありがとう
5. 夏だね

この5個で見るポイント:

- あんりぃが別犬化していないか
- 文字がLINEの小サイズでも読めるか
- 小物が安っぽくないか
- 背景なしでも商品感があるか
- 40個並べた時に統一感が出そうか

## 生成プロンプト方針

犬本体を生成するプロンプトは原則使わない。

小物だけ生成する場合の例:

```text
High-quality cute summer sticker prop asset only, transparent background, premium Japanese kawaii style, soft watercolor texture with clean edges, subtle realistic shading, no dog, no animal, no character, no text, centered object, LINE sticker compatible.

Object: {summer prop}
Mood: gentle, refreshing, warm, polished, not cheap
Colors: pastel summer colors with natural shadows
```

文字デザインを作る場合の例:

```text
Japanese LINE sticker text design only, transparent background, bold rounded hand-lettering, highly readable at small size, white outline, soft dark brown shadow, premium cute summer style, no character, no dog, no background.

Text: {Japanese text}
Color mood: {summer color}
```

## 判定基準

採用条件:

- ぱっと見で「あんりぃ」と分かる
- 小物や文字より顔が主役
- 文字が一瞬で読める
- 夏特集に入っていて自然
- 40個セットで買いたくなる統一感がある

不採用条件:

- 目、鼻、耳、毛並みが変わる
- 顔が隠れる
- 背景がうるさい
- 小物が幼稚、雑、安い
- 文字がテンプレ感だけで魅力がない
